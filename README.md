# Paired Wellness

A responsive four-page brand website for Annie DeNome’s Christ-centered wellness, skincare, and educational work.

## Pages

| Route | Purpose |
|---|---|
| `/` | Editorial introduction to the Paired Wellness method, Annie’s story, gut restoration, skin support, and upcoming guides |
| `/about` | Annie’s verified biography, personal wellness testimony, root-cause journey, and faith-centered principles |
| `/skincare` | Annie’s inside-and-out skincare philosophy, Crunchi and RINGANA partnerships, and routine reset |
| `/guides` | A coming-soon library for acne, skincare, gut health, foundational labs, faith, and everyday wellness resources |

## Local development

```bash
npm install
npm run dev
```

Create a production bundle with:

```bash
npm run build
```

## Design system

The current design follows the supplied Paired Wellness editorial reference: warm white and pale blush fields, asymmetric image grids, thin rules, high-contrast serif typography, small underlined labels, restrained motion, and generous negative space. Interactive elements remain clear and accessible without introducing card-heavy or app-like decoration.

| Color | Value |
|---|---:|
| Paper | `#FBFAF7` |
| Editorial Blush | `#F0ECEB` |
| Ink | `#171816` |
| Moss | `#526247` |
| Pear | `#C9D675` |

Typography pairs **Cormorant Garamond** for editorial display and reading text with **DM Sans** for navigation and utility copy.

## Photography policy

The site prioritizes Annie’s real photography. Her approved portrait appears across the Home, About, Skincare, and Guide experiences; the official Annie-and-Ryan photograph supports the Health in the Spirit content; and the staircase portrait was extracted from the user-supplied Paired Wellness template for the contact section. Botanical imagery is limited to the opening pear motif and one restrained orchard story where personal photography is not available.

## Content and attribution

Biographical and brand details were synthesized from Annie’s public Instagram profile, Annie’s public Linktree, and the official [Health in the Spirit](https://healthinthespirit.com/) site and podcast feed. The site includes an educational disclaimer and avoids diagnostic language, treatment instructions, or guarantees of individual outcomes. Partner relationships are transparently identified. RINGANA currently routes to Annie’s Instagram because a verified public partner-shopping URL was not available during the build.
