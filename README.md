# Annie B Wellness

A responsive four-page brand website for Annie DeNome’s Christ-centered wellness, skincare, and educational work.

## Pages

| Route | Purpose |
|---|---|
| `/` | Brand introduction, pathways, testimony, skincare partners, guide preview, and podcast invitation |
| `/about` | Annie’s verified biography, personal wellness testimony, beliefs, and life notes |
| `/skincare` | Inside-and-out skincare philosophy, Crunchi and RINGANA partnerships, and routine principles |
| `/guides` | Placeholder library for acne, skincare, gut health, foundational labs, faith, and everyday wellness resources |

## Local development

```bash
npm install
npm run dev
```

Create a production bundle with:

```bash
npm run build
```

## Design system

The visual direction uses the supplied editorial wellness references: arched frames, minimal-boho spacing, paper texture, precise rules, high-contrast serif typography, and a restrained brand palette.

| Color | Value |
|---|---:|
| Pear | `#C3DB5F` |
| Gunmetal | `#00292D` |
| Myrtle Green | `#3C756F` |
| Ash Gray | `#C2D6C8` |
| Isabelline | `#F9F4EE` |

Typography pairs **Cormorant Garamond** for editorial display text with **DM Sans** for body copy and navigation.

## Content and attribution

Biographical and brand details were synthesized from Annie’s public Instagram profile, Annie’s public Linktree, and the official [Health in the Spirit](https://healthinthespirit.com/) site and podcast feed. The two local portraits are public press/biography assets from the official Health in the Spirit website.

The site includes an educational disclaimer and avoids diagnostic language, treatment instructions, or guarantees of individual outcomes. Partner relationships are transparently identified. RINGANA currently routes to Annie’s Instagram because a verified public partner-shopping URL was not available during the build.
